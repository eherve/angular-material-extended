# Changelog

## 22.1.0 — 2026-10-22

- Use the header contrast color for subtitles so they remain readable on themed headers.

## 22.0.5 — 2026-10-20

- Render the single autocomplete prefix only when provided, preserving Material left padding for values without a prefix.

## 22.0.4 — 2026-10-19

- Use compact danger-colored clear buttons on text, textarea, numeric, duration, select, search, date/time and slider fields.
- Hide clear buttons on empty or disabled fields; preserve zero and false selections.
- Clear only the search draft in multiple autocomplete and sortable-list add inputs, preserving selected items.
- Keep multiple-select separators attached to the preceding label.
- Add clear actions to time and range fields, preserving the other endpoint when clearing a split range.
- Keep checkbox, radio and chip toggle fields without a dedicated clear button.
